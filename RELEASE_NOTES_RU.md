# ZeTer Video Downloader — Windows-сборка 6.24

- Обновлён интерфейс загрузчика: очередь, прогресс и параметры видны в главном окне. В README показана загрузка демонстрационной очереди.
- Можно очищать очередь с сохранением истории и выбирать, пропускать ли ранее скачанные ролики.
- Восстановление загрузки и проверка готовых MP4 и MP3 улучшены.
- Проверки длинных путей, очистки временных папок и восстановления очереди учитывают особенности Windows и Linux.
- В документации описана сквозная проверка очистки очереди и сохранности истории после перезапуска.
- Основной файл запуска из исходников — `ZeTer Video Downloader .py`.
- После ошибки создания MP3 готовое видео остаётся в папке «Видео». Кнопка «Продолжить очередь» повторяет создание MP3 из сохранённых роликов.
- Названия вроде `lesson.f137` больше не мешают сохранению готового MP4. Очередь правильно различает ссылки разных сайтов, а ссылки YouTube Live и обычные ссылки одного ролика объединяет.
- Плейлист сохраняет выбор при переключении фильтра, быстро открывает большие списки и получает недостающие названия в фоне.
- Проверка видео переиспользуется в пределах очереди для неизменённых файлов.
