# ZeTer Video Downloader — Windows-сборка 6.3 (23 октября 2026)

**Обновления приложения (23 октября 2026):** Windows EXE теперь содержит идентификатор сборки `build-<commit>`, при запуске фоново проверяет новые сборки на GitHub Releases и предлагает установку только после согласия пользователя. Скачанный EXE проверяется по SHA-256, замена выполняется после закрытия программы с резервной копией и восстановлением при ошибке. Настройки, история и файлы пользователя сохраняются.

**Источник:** исходники из пользовательского архива от 23 октября 2026 года, опубликованные в `main`.

## Что обновлено

- **Новое название:** ZeTer Video Downloader. Изменены название окна, сведения о Windows EXE, имя готового файла, адрес репозитория и имена release assets. В Windows-сборке теперь используется `ZeTer-Video-Downloader.exe`.
- **Переход с прежних выпусков:** владельцам `Universal-Video-Downloader.exe` необходимо один раз скачать новый EXE вручную и разместить его в существующей папке приложения после закрытия старой версии. Старый updater не распознаёт переименованный release asset; пользовательские каталоги не нужно удалять.
- Совместимость: идентификатор формата старых диагностических файлов сохранён; проверяется новая метка сборки и корректная идентификация устаревшего manifest.

- Исправлен старт загрузки при работе через VPN, системный прокси и обычную сеть: yt-dlp использует фактический сетевой маршрут Windows без блокирующей прямой TCP-проверки; явно заданный прокси по-прежнему поддерживается.
- Исправлена очистка пустых временных каталогов после завершения очереди без удаления пользовательских файлов; непустые каталоги и небезопасные перенаправления пути сохраняются.
- Доработан выбор качества YouTube: готовые потоки видео+аудио рассматриваются наравне с раздельными, сохраняется приоритет Full HD не выше 1080p и предпочтение русской аудиодорожки, когда она доступна.
- Устранены повторные неудачные попытки в одной очереди: проверенные проблемы IPv6 DNS, Chrome cookies и отдельных клиентских профилей временно исключаются; ограничения сбрасываются при новой очереди.
- Улучшены распознавание ошибок доступа/авторизации (в том числе русскоязычных сообщений), бюджеты повторов, резервные стратегии скачивания и учет итогов очереди.
- Усилена диагностика: запись итоговых событий, атомарное сохранение JSON, устойчивость к Windows file lock и emergency-логирование.
- Добавлены сочетания Ctrl+X / Ctrl+A в поле ссылок для русской и английской раскладок; сохранены Ctrl+C / Ctrl+V.
- Сохранены возможности уведомления по завершении и блокировки выбора папки во время выполнения задачи.
- Расширены offline-регрессионные тесты выбора качества, поведения очереди, диагностики и UI.

## Windows EXE

GitHub Actions компилирует проект, запускает offline-тесты на Linux и Windows, собирает **ZeTer-Video-Downloader.exe** через PyInstaller и выполняет проверку готового EXE (`--self-test`). В поставку включены **yt-dlp, FFmpeg, ffprobe и Deno**. Рядом с EXE публикуется файл SHA-256 для проверки целостности.

Локальная предварительная проверка объединённых исходников: **158 тестов выполнены без ошибок, 15 пропущены** в доступной среде; `compileall` прошёл. Это не заменяет проверку Windows-бинарника в GitHub Actions. Реальные сетевые загрузки и графический интерфейс в данном окружении не проверялись.

**Ограничения:** файл EXE не имеет коммерческой цифровой подписи, поэтому Windows SmartScreen может предупреждать о новом приложении. Работа видеосайтов зависит от сети, внешних сервисов и изменений в yt-dlp. Соблюдайте условия сайтов и авторские права.
