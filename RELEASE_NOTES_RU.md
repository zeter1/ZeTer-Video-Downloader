# Universal Video Downloader — Windows-сборка 6.3 (22 октября 2026)

**Источник:** актуальная версия `main` после загрузки исходников от 22 октября 2026 года.

## Что обновлено

- Доработан выбор качества YouTube: готовые потоки видео+аудио рассматриваются наравне с раздельными, сохраняется приоритет Full HD не выше 1080p и предпочтение русской аудиодорожки, когда она доступна.
- Устранены повторные неудачные попытки в одной очереди: проверенные проблемы IPv6 DNS, Chrome cookies и отдельных клиентских профилей временно исключаются; ограничения сбрасываются при новой очереди.
- Улучшены распознавание ошибок доступа/авторизации (в том числе русскоязычных сообщений), бюджеты повторов, резервные стратегии скачивания и учет итогов очереди.
- Усилена диагностика: запись итоговых событий, атомарное сохранение JSON, устойчивость к Windows file lock и emergency-логирование.
- Добавлены сочетания Ctrl+X / Ctrl+A в поле ссылок для русской и английской раскладок; сохранены Ctrl+C / Ctrl+V.
- Сохранены возможности уведомления по завершении и блокировки выбора папки во время выполнения задачи.
- Расширены offline-регрессионные тесты выбора качества, поведения очереди, диагностики и UI.

## Windows EXE

GitHub Actions компилирует проект, запускает offline-тесты на Linux и Windows, собирает **Universal-Video-Downloader.exe** через PyInstaller и выполняет проверку готового EXE (`--self-test`). В поставку включены **yt-dlp, FFmpeg, ffprobe и Deno**. Рядом с EXE публикуется файл SHA-256 для проверки целостности.

Локальная предварительная проверка объединённых исходников: **135 тестов выполнены без ошибок, 14 пропущены** в доступной среде; `compileall` прошёл. Это не заменяет проверку Windows-бинарника в GitHub Actions. Реальные сетевые загрузки и графический интерфейс в данном окружении не проверялись.

**Ограничения:** файл EXE не имеет коммерческой цифровой подписи, поэтому Windows SmartScreen может предупреждать о новом приложении. Работа видеосайтов зависит от сети, внешних сервисов и изменений в yt-dlp. Соблюдайте условия сайтов и авторские права.
