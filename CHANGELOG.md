# История изменений

### 2026-10-22 — Переименование в ZeTer Video Downloader

- Приложение теперь называется **ZeTer Video Downloader** в заголовке окна, документации, диагностическом манифесте и карточке Windows EXE.
- Windows-сборка и контрольная сумма публикуются как `ZeTer-Video-Downloader.exe` и `ZeTer-Video-Downloader.sha256.txt`; обновлены пути релизов и встроенная идентификация сборки под `zeter1/ZeTer-Video-Downloader`.
- Идентификаторы исторической схемы диагностических JSONL сохранены для совместимости; добавлено распознавание ранее выпущенного build manifest и регрессионные тесты брендинга.
- Для перехода со старого `Universal-Video-Downloader.exe` нужна **разовая ручная установка нового EXE** в прежнюю папку: старый updater не может определить переименованный asset в новом репозитории. Настройки, история и логи должны остаться без изменений.

### 2026-10-22 — Обновление Windows-приложения через GitHub Releases

- В Windows EXE встраивается идентификатор `build-<commit>` для определения установленного выпуска независимо от отображаемой версии 6.3.
- Добавлена фоновая проверка новых prerelease-сборок, кнопка ручной проверки и возможность отключить проверку при запуске.
- Перед установкой новая сборка скачивается с GitHub с проверкой SHA-256; замена EXE выполняется после закрытия программы с резервной копией и откатом при сбое. История загрузок, настройки и логи не изменяются.
- Без достоверного идентификатора старого/стороннего EXE автоматическая замена запрещена; предложен безопасный ручной переход к Releases.
- Добавлены offline-тесты идентификации, выбора релиза и проверки контрольной суммы; Windows-сборка проверяет наличие встроенной идентификации.

История фиксируется с этой задачи; прежние изменения здесь не восстановлены. Номер новой версии не назначен: в проекте нет установленного правила увеличения версии.

### 2026-10-22 — GitHub-поставка исходников и совместимость EXE

- Integration: сохранены поддержка PyInstaller `--onefile` (путь к каталогу EXE и `_MEIPASS`), автоматическое обнаружение встроенных yt-dlp/FFmpeg/ffprobe/Deno и проверка `--self-test`.
- Integration: сохранена версия приложения 6.3; обновления скачивания, диагностики и тестов перенесены поверх существующей Windows-сборки без отката возможностей.
- Verification: 135 offline-тестов в объединённом дереве прошли без ошибок (14 пропущены в данной среде), компиляция прошла. Windows EXE и реальные онлайн-загрузки требуют проверки в GitHub Actions/Windows.
