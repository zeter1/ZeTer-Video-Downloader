# ZeTer Video Downloader

[![Python checks](https://github.com/zeter1/ZeTer-Video-Downloader/actions/workflows/python-check.yml/badge.svg)](https://github.com/zeter1/ZeTer-Video-Downloader/actions/workflows/python-check.yml)
[![Releases](https://img.shields.io/badge/Windows-EXE%20Releases-blue?logo=github)](https://github.com/zeter1/ZeTer-Video-Downloader/releases)

**ZeTer Video Downloader** — настольная программа для Windows, которая скачивает видео с сайтов, поддерживаемых [yt-dlp](https://github.com/yt-dlp/yt-dlp), сохраняет видео в **MP4 до 1080p** и автоматически создаёт **MP3** из успешно скачанных роликов.

Программа объединяет загрузку, обработку медиа, очередь ссылок, проверку результатов и диагностику в одном интерфейсе. Для обычного использования достаточно готового EXE: **Python, FFmpeg и другие инструменты отдельно устанавливать не требуется**.

**[📥 Скачать для Windows](https://github.com/zeter1/ZeTer-Video-Downloader/releases)** · **[📖 История изменений](CHANGELOG.md)** · **[🐞 Сообщить об ошибке](https://github.com/zeter1/ZeTer-Video-Downloader/issues/new/choose)**

> **Важно:** опубликованные Windows-сборки имеют статус **Prerelease** и пока не подписаны коммерческим сертификатом. Работа сайтов зависит от их правил, доступности сети и поддержки в yt-dlp.

## Быстрый старт

**Поддерживаемая сборка:** Windows x64, отдельный файл `ZeTer-Video-Downloader.exe` (без установщика).

1. Откройте **[GitHub Releases](https://github.com/zeter1/ZeTer-Video-Downloader/releases)**. Поскольку сборки помечены *Prerelease*, выбирайте свежий опубликованный выпуск в списке релизов, а не полагайтесь на ссылку GitHub `/releases/latest`.
2. В разделе **Assets** скачайте `ZeTer-Video-Downloader.exe`. Файл `ZeTer-Video-Downloader.sha256.txt` нужен только для самостоятельной проверки контрольной суммы.
3. Поместите EXE в **отдельную папку с правом записи**, например `Документы\ZeTer-Video-Downloader`, и запустите его. Не рекомендуется папка `Program Files`: приложение хранит настройки и журналы рядом с EXE.
4. Вставьте URL видео (каждая ссылка — с новой строки), выберите папку сохранения и нажмите **«▶ Скачать все»**.
5. Найдите результат в подпапках **`Видео`** и **`Аудио`** выбранного каталога.

> **Переход со старого названия:** если у вас установлен `Universal-Video-Downloader.exe`, скачайте новый `ZeTer-Video-Downloader.exe` из Releases и **один раз обновитесь вручную**: закройте старую программу и положите новый EXE в ту же папку. Тогда каталоги `Настройки`, `Логи скачивания`, `Логи проблем` и история останутся на месте. Старый механизм обновления не распознаёт переименованные ассеты нового репозитория; не удаляйте данные и не запускайте обе версии одновременно.

В Windows-сборку через PyInstaller включены **yt-dlp, FFmpeg, ffprobe и Deno**. Не нужно отдельно скачивать Python или устанавливать пакет `requirements.txt`. Для загрузки нужен интернет; некоторые сайты могут требовать авторизацию или быть недоступны в вашей сети.

> Если Windows SmartScreen предупреждает о неизвестном издателе, сначала проверьте, что EXE получен именно из Releases этого репозитория, и при необходимости сверьте SHA-256. Предупреждение связано в том числе с отсутствием цифровой подписи; оно не является доказательством ни безопасности, ни вредоносности файла.

## Возможности

| Возможность | Как работает |
| --- | --- |
| **Видео в MP4** | Автоматический приоритет качества класса 1080p и строгий максимум 1080 строк по высоте; если нужного формата нет, используется доступное качество ниже |
| **MP3** | После загрузки видео программа автоматически извлекает аудио из успешно скачанных роликов; качество: 128/192/256/320 кбит/с или VBR-0 |
| **Обработка без лишних потерь** | По возможности прямые MP4/M4A-потоки или remux без перекодирования; H.264/AAC — резервный вариант |
| **Очередь ссылок** | Несколько URL, удаление дублей и учёт ранее скачанных видео; до 500 ссылок в одной сессии |
| **HTML-плейлисты YouTube** | Импорт сохранённого HTML, выбор роликов и фильтрация уже скачанных |
| **Параллельные загрузки** | Настройка от 1 до 2 одновременных загрузок |
| **Аудио в один файл** | Необязательное объединение успешно созданных MP3 с возможностью разбивки по продолжительности |
| **Дополнительные возможности** | Субтитры при доступности, обработка сетевых сбоев, резервные стратегии yt-dlp, уведомления о завершении |
| **Диагностика** | Лог в интерфейсе, журналы сессий, проблемные ссылки для повторной обработки и структурированные отчёты об ошибках |
| **Обновления** | Фоновая проверка GitHub Releases и подтверждаемая пользователем замена проверенного EXE |

**Важно про режимы:** в текущем интерфейсе **нет отдельного переключателя «только видео / только MP3»**. В обычной сессии приложение сначала скачивает видео, а затем конвертирует его в MP3. Это отражает фактическое поведение текущего кода.

## Использование

### Обычная загрузка

1. Скопируйте ссылку на видео с сайта, поддерживаемого yt-dlp.
2. Вставьте одну или несколько ссылок в поле **«Ссылки для скачивания»**, каждую с новой строки. Можно воспользоваться кнопкой **«📋 Вставить из буфера»**.
3. Укажите **«Путь сохранения»**. Видео сохраняются с приоритетом Full HD (до 1080p); качество видео в интерфейсе не переключается.
4. При необходимости задайте качество MP3, включите субтитры и измените число потоков.
5. Нажмите **«▶ Скачать все»**. Ход работы виден во вкладках **«Весь лог загрузки»**, **«Не скачалось»** и **«Ошибки»**.
6. Дождитесь окончания загрузки и последующей конвертации в MP3. Если задача завершена, программа покажет уведомление. Кнопка **«⏹ Отменить»** останавливает работу.

В поле ссылок работают **Ctrl+C** (копировать), **Ctrl+X** (вырезать), **Ctrl+A** (выделить всё) и **Ctrl+V** (вставить) при русской и английской раскладках, с включённым и выключенным NumLock.

После завершения очереди пустые служебные папки **`_temp_downloads`** и **`_quality_candidates`** внутри `Видео` удаляются автоматически. Непустые папки с незавершёнными загрузками или материалами восстановления сохраняются.

Повторные ссылки в одной очереди удаляются. Ранее скачанные видео по умолчанию пропускаются на основе сохранённой истории. Кнопка **«🗂 Очистить лог скачанных»** сбрасывает этот учёт; используйте её осознанно.

### Импорт HTML-плейлиста YouTube

1. Сохраните страницу плейлиста в виде HTML-файла.
2. Нажмите **«📂 Загрузить плейлист из .html»** и выберите файл.
3. В списке выберите нужные видео (или **«Только новые»**) и нажмите **«Добавить выбранные в очередь»**.
4. Запустите общую очередь кнопкой **«Скачать все»**.

Импорт зависит от структуры сохранённой HTML-страницы YouTube: произвольный HTML и любые версии разметки не гарантируются.

### Объединение аудио

Установите **«Объединить все аудио в один файл»**. При необходимости задайте разбивку по часам: **0** — без разбивки, до **10** часов на часть. Объединяются **только MP3, успешно полученные в текущей сессии**, даже если часть видео загрузить не удалось.

### Как получается MP4

```text
URL → yt-dlp → выбор формата (приоритет 1080p, максимум 1080p)
                      ↓
       совместимые исходные потоки / раздельные видео + аудио
                      ↓
       MP4 напрямую или remux без потери качества
                      ↓
       при необходимости H.264/AAC transcoding
                      ↓
       проверка результата через ffprobe
                      ↓
           Видео/*.mp4 → Аудио/*.mp3
```

Выбор формата зависит от возможностей исходного сайта. Наличие ролика на YouTube не означает, что любой конкретный формат или аудиодорожка будет доступна.

## Где сохраняются файлы

Папки **`Видео`** и **`Аудио`** создаются **внутри выбранного каталога сохранения**. Служебные данные хранятся **рядом с EXE** (или в корне проекта при запуске из исходников).

| Путь относительно программы | Назначение |
| --- | --- |
| `Настройки/settings.json` | Настройки приложения, в том числе путь сохранения и автоматическая проверка обновлений |
| `Логи скачивания/` | Журналы работы и учёт загруженных URL |
| `История ссылок/` | История успешно обработанных ссылок по сессиям |
| `Ссылки на скачивания/` | Списки ссылок из очереди, сохраняемые при закрытии |
| `Обработать вручную/` | Неудачные или проблемные загрузки и результаты, требующие внимания |
| `Логи проблем/` | Диагностические сессии, события и отчёты (если запись включена) |
| `Обновления/build-.../` | Скачанные кандидаты EXE и, при неудачной установке, `update-error.log` |

**Хранение логов:** приложение предусматривает автоматическую очистку части истории и диагностических данных по срокам хранения (60 и 120 дней соответственно). Если материалы нужны для разбора ошибки, сохраните копию заранее.

## Обновления приложения

Готовые сборки публикуются на [GitHub Releases](https://github.com/zeter1/ZeTer-Video-Downloader/releases) с тегами вида `build-7ab3f9f`. Этот идентификатор — **ревизия сборки**, а не номер пользовательской версии; отображаемая версия приложения может оставаться `6.3` между разными сборками.

- **Автоматическая проверка:** по умолчанию после запуска EXE проверяет опубликованные релизы в фоне. Отключается галочкой **«Проверять обновления при запуске»**.
- **Ручная проверка:** кнопка **«🔄 Проверить обновления»**.
- **Установка:** при обнаружении более новой распознанной сборки программа предлагает скачать EXE, проверяет **SHA-256 из метаданных релиза GitHub** и только после подтверждения пользователя закрывает приложение для замены. При ошибке установки предусмотрено восстановление предыдущего EXE.
- **Защита данных:** механизм обновления не должен удалять папки с настройками, историей и скачанными файлами. Для замены EXE требуется право записи в его каталог.
- **Старые EXE:** сборки без встроенного идентификатора не могут безопасно определить свою версию — **один раз скачайте новый EXE вручную**. Запуск из исходников не поддерживает самозамену EXE.

**Не запускайте обновление во время скачивания видео.** Если GitHub недоступен, проверка обновления может завершиться ошибкой; обычная работа программы от этого не зависит. Самообновление запущенного Windows EXE на разных пользовательских компьютерах не является эквивалентом тестов сборки в CI.

**Обновление yt-dlp — отдельный процесс.** В готовый EXE yt-dlp встроен при сборке: `pip install -U yt-dlp` или `Обновление yt-dlp.bat` **не заменят встроенную копию внутри EXE**. Для готового приложения получайте новую сборку из Releases; для запуска из исходников обновляйте Python-пакет через pip.

## Проверка скачанного EXE

При желании скачайте рядом с EXE файл `ZeTer-Video-Downloader.sha256.txt` из **того же релиза**. В PowerShell, находясь в папке с двумя файлами:

```powershell
(Get-FileHash .\ZeTer-Video-Downloader.exe -Algorithm SHA256).Hash
Get-Content .\ZeTer-Video-Downloader.sha256.txt
```

Сравните полученные 64 шестнадцатеричных символа со значением в начале файла `.sha256.txt`. **Они должны совпадать.** Контрольная сумма выявляет расхождение файла с опубликованной сборкой, но сама по себе не заменяет проверку доверия к источнику и цифровую подпись.

## Запуск из исходников

Для разработчиков и пользователей, которым нужен запуск Python-версии.

**Требования:** Windows, Python **3.12** (версия, используемая в CI), Git, [FFmpeg](https://ffmpeg.org/) с `ffmpeg` и `ffprobe` в `PATH`. `yt-dlp` устанавливается из `requirements.txt`. Для некоторых сценариев YouTube дополнительно полезен [Deno](https://deno.com/) или Node.js.

```powershell
git clone https://github.com/zeter1/ZeTer-Video-Downloader.git
cd ZeTer-Video-Downloader

py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe video_downloader.py
```

Проверка инструментов:

```powershell
ffmpeg -version
ffprobe -version
.\.venv\Scripts\python.exe -m yt_dlp --version
```

Не путайте Python-версию с готовым EXE: среда разработки и сторонние инструменты требуются только для запуска из исходников. На Linux выполняются автоматические тесты, но основная пользовательская сборка и интерфейс ориентированы на Windows.

## Решение проблем

| Симптом | Что проверить |
| --- | --- |
| **Программа не скачивает видео** | Интернет, доступность ссылки в браузере, ограничения сайта, актуальность EXE/yt-dlp; вкладку **«Не скачалось»** |
| **На YouTube ошибка формата, 403, timeout** | Обновлённый yt-dlp, доступность Deno/Node в исходной версии, сетевые ограничения/VPN/прокси; журнал конкретной попытки |
| **Видео есть, MP3 не создан** | Есть ли в исходном ролике аудиодорожка; сообщения FFmpeg и результат проверки длительности |
| **Ссылка пропущена** | Уже скачанный ролик или дубликат в очереди; при необходимости проверяйте историю |
| **Не получается установить обновление** | Права на запись в папку EXE, отсутствие активной загрузки, `Обновления/build-.../update-error.log`; при необходимости установите свежий EXE вручную |
| **Не хватает инструментов при запуске исходников** | Наличие `ffmpeg`, `ffprobe`, `yt-dlp` и их доступность через `PATH` / Python-окружение |

Для воспроизводимой ошибки укажите версию **`build-...`**, Windows, сайт, ожидаемое и фактическое поведение, шаги воспроизведения и **обезличенный** фрагмент логов. Начните с `Логи проблем/latest_run.json` и нужной папки `Логи проблем/Сессии/<запуск>/`, если диагностика включена.

**[Инструкция для отчёта об ошибке](SUPPORT.md)** · **[Создать issue](https://github.com/zeter1/ZeTer-Video-Downloader/issues/new/choose)** · **[Правила безопасности](SECURITY.md)**

> **Приватность:** перед отправкой логов удалите cookie, токены, заголовки авторизации, приватные URL и чувствительные локальные пути. Лог может содержать сведения об используемых сайтах и файлах.

## Архитектура

Проект организован по областям ответственности, чтобы изменение загрузчика, интерфейса или диагностики не требовало правки одного гигантского файла.

```text
video_downloader.py → src/bootstrap.py → src/application.py
                                           ├── src/app/          пути и состояние
                                           ├── src/core/         runtime, настройки, subprocess, обновления
                                           ├── src/downloads/    URL, очереди, yt-dlp, качество, проверка MP4
                                           ├── src/audio/        конвертация, объединение, разбивка MP3
                                           ├── src/ui/           Tkinter, уведомления, проверка обновлений
                                           └── src/diagnostics/  ошибки, события, отчёты и retention
tests/               offline-регрессии
scripts/             инструменты навигации и проверки структуры
.github/workflows/   CI, Windows EXE, GitHub Releases
```

Ключевые инженерные решения:

- **Контракт формата:** максимум 1080p, приоритет подходящих потоков, проверка фактического видео через ffprobe и MP4 на выходе.
- **Recovery-first:** резервные стратегии yt-dlp, ограничение повторов, обработка зависаний и отмены процессов без отключения полезной диагностики.
- **Диагностика:** структурированные события и сессии, сводки результатов, ограничение размеров и сроков хранения.
- **Windows-поставка:** PyInstaller `--onefile`, встроенные инструменты, `--self-test`, SHA-256 и отдельный updater с идентификатором сборки.
- **AI-friendly навигация:** явные owner-модули и скрипт, который предлагает минимальную область изучения для Codex/ChatGPT.

**Документация:** [Архитектура](docs/ARCHITECTURE.md) · [Карта кода](docs/CODE_MAP.md) · [Индекс модулей](docs/CODE_INDEX.md) · [Workflow Codex](docs/CODEX_WORKFLOW.md) · [Инструкции для агента](AGENTS.md)

## Тестирование и сборка

Базовые offline-проверки:

```powershell
.\.venv\Scripts\python.exe -m compileall -q video_downloader.py problem_log_validator.py src scripts tests
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe scripts/check_codex_efficiency.py
```

В [GitHub Actions](https://github.com/zeter1/ZeTer-Video-Downloader/actions/workflows/python-check.yml) обычные изменения Python-кода запускают компиляцию и тесты на Ubuntu. **Windows EXE создаётся отдельно**: при ручном запуске workflow либо push-коммите с `[package]` после успешных тестов. Windows-job повторно запускает offline-тесты, собирает EXE через PyInstaller, выполняет `--self-test` встроенных инструментов и публикует EXE и SHA-256 в GitHub Release.

Изменение только README **не публикует новый бинарник**. Релизные сборки проверяются в CI, однако автотесты не гарантируют работоспособность всех внешних сайтов и не заменяют ручную проверку графического интерфейса и реального обновления EXE.

- **Сайты и авторизация:** поддержка ограничена возможностями yt-dlp, настройками доступа и условиями конкретного сайта. Нет гарантии скачивания приватного, платного или защищённого контента.
- **Качество:** видео не выше 1080p; 1080p не гарантируется, если нужный формат недоступен у источника.
- **Аудио:** MP3 создаётся только для успешно скачанных файлов с доступной аудиодорожкой.
- **Платформа:** готовый EXE публикуется для Windows x64 и не имеет коммерческой цифровой подписи.
- **Правомерное использование:** скачивайте только контент, на который у вас есть права, с учётом авторского права и условий сервисов.
